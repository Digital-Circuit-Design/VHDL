4. Multiplexer 4-in-1 
A 4-in-1 multiplexer takes a 4-digit data input and a 2-digit control input and 
has a one-digit input which is one of the data inputs depending on the combination of 
values of the selection input. 

_________________________________________ mux_4to1.vhd _____________________________________________
-- 4-to-1 multiplexer code
LIBRARY ieee?
USE ieee.std_logic_1164.all;

ENTITY mux_4to1 IS 
PORT(
a : IN std_logic_vector(4 DOWNTO 1);
s : IN std_logic_vector(2 DOWNTO 1);
d : OUT std_logic);;
END mux_4to1;

ARCHITECTURE dataflow OF mux_4to1 IS 
BEGIN
WITH s SELECT
d <= a(1) WHEN "00",
a(2) WHEN "01",
a(3) WHEN "10",
a(4) WHEN OTHERS;
END dataflow;

outputs are 0.
Implement the circuit using only the <= instruction (based on the logic circuit)

_____________________________________________ dec2to4.vhd _____________________________________________
-- 2-in-4 decoder code with permission
LIBRARY ieee?

PORT(
a : IN std_logic_vector(2 DOWNTO 1);
en : IN std_logic;

END dec2to4;

ARCHITECTURE dataflow OF dec2to4 IS
SIGNAL en_a : std_logic_vector(3 DOWNTO 1);; 
BEGIN
en_a <= en & a;
WITH en_a SELECT
d <= "0001" WHEN "100",
"0010" WHEN "101",
"0100" WHEN "110",
"1000" WHEN "111",
"0000" WHEN OTHERS;
END dataflow;;

_____________________________________________ fa.vhd _____________________________________________
-- Full adder code
LIBRARY ieee?
USE ieee.std_logic_1164.all;

ENTITY fa is
PORT(
A, B, Cin : IN bit;
S, Cout : OUT bit);;
END fa;

ARCHITECTURE dataflow OF fa IS
SIGNAL xor_AB : bit;
SIGNAL and_AB : bit;
SIGNAL and_xorAB_Cin : bit;
BEGIN
xor_AB <= A XOR B;
S <= xor_AB XOR Cin;
and_AB <= A AND B;
and_xorAB_Cin <= xor_AB AND Cin;
Cout <= and_AB OR and_xorAB_Cin;
END dataflow;

10. 4 bit adder
Implement a 4 bit adder circuit.

_____________________________________________ adder4.vhd _____________________________________________
-- 4 bit adder code
LIBRARY ieee?
USE ieee.std_logic_1164.all;
USE ieee.std_logic_unsigned.all;

ENTITY adder4 IS
PORT(
Cin : IN std_logic;
X, Y : IN std_logic_vector(3 DOWNTO 0);
S : OUT std_logic_vector(3 DOWNTO 0);
Cout : OUT std_logic);;
END adder4;

ARCHITECTURE dataflow OF adder4 IS
SIGNAL Sum : std_logic_vector(4 DOWNTO 0);
BEGIN
Sum <= ('1' & X) + Y + Cin;
S <= Sum(3 DOWNTO 0);
Cout <= Sum(4);
END dataflow;
